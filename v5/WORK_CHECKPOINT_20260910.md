# 2026-09-10 작업 체크포인트

## 현재 상태

- 공개 기준은 v5.1.10. 작업 트리는 v5.2.0 후보이며 아직 릴리스/유선 설치/안정 버전 지정하지 않았다.
- 사용자 실기 보고: 안정 버전 등록 완료 후에도 보라색 업데이트 화살표가 남는다. 단순 대기 시간 문제로 확정하면 안 된다.
- 현재 /dev/ttyUSB0, /dev/ttyACM0 모두 없으므로 이 증상의 실제 내부 상태는 확인하지 못했다.

## 후보 변경

- 업데이트 확인은 서명된 작은 메타데이터 확인과 전체 BIN 다운로드를 분리한다. 확인한 버전으로 다운로드 URL을 고정한다.
- 업데이트 발견 후 물리 OK로 설치 준비 다운로드, 전체 검증 후 OK로 설치한다. BACK 취소를 유지한다.
- 별도 서명된 STABLE 지정문을 확인하는 백그라운드 다운로더와 SD 보관 경로를 추가했다. 기존 stable 인덱스/폴더를 유지하고 일반 설치 완료가 임의로 stable을 승격하지 않게 했다.
- 통합 명령에 stable VERSION 하위 명령을 추가했다. 실제 게시 실행 전 도구 검증이 더 필요하다.
- 보라색 표시에서 안정성 대기와 SD 안정 버전 보관을 제외했다. 표시 변화 시 bundle/SD/ZERO 상태를 UART0에 남긴다. 실제 기기의 지속 표시 원인이 확정된 것은 아니다.

## 검증

- ./tools/test-core.sh 및 ./tools/test-v5.sh 모두 통과 (5.2.0 문서 계약 포함).
- 안정 버전 보관 회귀 테스트: 서명 오류/인덱스 실패 시 기존 안정 버전 보존, flash 설치 및 설치 journal 변경 없음, 동일 버전 재확인 시 BIN 재다운로드 없음.
- 최종 변경 이후 MAIN/ZERO/SAFE 전체 빌드와 서명 검증은 아직 필요하다.
- 최신 소스의 실제 버튼/OTA/SPI/보라색 표시/SD stable 저장은 미확인이다.

## 다음 작업

1. stable 게시 도구 및 백그라운드 취소 후 ZERO 다운로드 요청 경합을 검토한다.
2. 기존 키로 공식 릴리스 도구 dry-run 전체 빌드를 수행한다.
3. USB 재연결 후 실제 버전/파티션/OTA 선택 상태를 읽고 백업한 다음 적절한 슬롯에 업로드한다. 현재 슬롯을 app0으로 가정하지 않는다.
4. 실기 검증을 통과한 버전만 공식 릴리스하고 stable로 지정한다. 서명 우회, 전체 지우기, 파티션 변경 금지.
