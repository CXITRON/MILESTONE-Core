# 업데이트 화면 한정 수정 체크포인트

## 요청 범위

- 기준 v5.2.1. 업데이트 결과·확인·다운로드·설치 화면만 수정한다.
- CORE/MEDIA/NOW/AP/모드 메뉴·상하단 상태바 디자인은 변경하지 않는다.
- ZERO 설치/부팅 점검 정지, 앨범 인터넷 검색 증상은 별도 미해결 사항이다.
  이번 UI 수정으로 해결했다고 주장하지 않는다.
- OTA 처리 순서·서명·키·파티션·물리 확인/취소 동작은 변경하지 않는다.

## 현재 작업

- 일반 스크롤 본문 대신 업데이트 전용 고정 레이아웃을 작성했다.
- 작은 구분 표시, 한글 제목, 큰 버전/진행률, KiB/MiB 전송량, 버튼 안내 분리.
- 오류는 실제 글꼴 폭에 따라 UTF-8 경계로 3줄 줄바꿈한다. 넘치는 경우 말줄임과
  설정 AP 상세 안내를 표시하며 원본 오류/진단/API는 그대로 유지한다.
- ZERO 준비/응답/부팅 점검은 바이트 진행률로 표시하지 않고 대기로 표시한다.
- 다운로드 본문은 화면 순환/스크롤 설정과 무관하게 250ms마다 갱신한다.
- 기존 호스트 테스트에 레이아웃 테스트 추가. 실제 U8g2 폰트의 픽셀 QA도 준비.

## 검증 체크포인트

- 작업 버전 v5.2.2로 문서/버전 동기화 완료.
- `./tools/test-core.sh`, `./tools/test-v5.sh` 전체 통과.
- 실제 설치된 U8g2 폰트로 12개 화면을 픽셀 렌더링해 검토했다.
  글자 누락·본문 128×128 밖 출력·텍스트 겹침 없음. 3줄 오류의 단어 단위 줄바꿈,
  긴 유효 버전, UINT32_MAX 크기/진행량, 0바이트 대기 및 UTF-8 경계를 검사했다.
- 해당 테스트가 검증하는 것은 표시 레이아웃이며, 실제 SPI/TFT 처리시간이나
  ZERO OTA 및 앨범 검색 성공을 검증한 것이 아니다.
- 변경된 `.ino` 실행 로직은 다운로드 본문 250ms 표시 갱신 조건뿐이다.
  기존 serviceButtons와 OTA/라디오/앨범 처리 코드는 그대로다.
